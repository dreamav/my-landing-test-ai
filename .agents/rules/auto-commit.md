# Git Workflow Rules

- **Auto-Commit**:
  - After each set of edits or modifications confirmed or requested by the user, automatically create a Git commit.
  - Commit author: `Meverick <reloved@gmail.com>`.
  - Commit messages should be clear, concise, and follow conventional commit format (e.g., `feat: ...`, `fix: ...`, `refactor: ...`).

- **Push on Completion ("заверши работу")**:
  - When the user writes "заверши работу" (or similar finish request), ensure all working changes are committed and push commits to the remote repository (`git push origin main` / current branch).
